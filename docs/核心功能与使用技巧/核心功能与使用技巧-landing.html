01 · 功能

为一场戏准备声音

四个核心能力，串起从剧本到围读的整条流水线。

  1. 智能拆剧本parsing

    按行区分场标、对白、动作与旁白，多集剧本按集排序、独立计场；疑似漏识别的行可一键设为场标或忽略。

  2. 声音设计voice design

    Qwen 用一句自然语言描述生成种子音色，试听满意后克隆固定，全剧声音统一；edge 模式直接分配，即开即用。

  3. 流式围读streaming

    边合成边播放，满 25 句即可提前进入围读，后台继续生成；当前句高亮跟随，0.5x-3x 倍速随时调。

  4. 跨集存档archive

    存档按“剧 → 集”两级落盘，每集独立保存音频与进度；角色音色按 roleBase 身份键跨集复用，音源锁在剧级。

两条路线怎么选：edge-tts 接近实时、需要联网，适合先听节奏；Qwen3 1.7B 全本地、首次加载较慢，适合定最终声音。同一部剧内不要混用两种音源。

02 · 原则

少即是好

四句话概括这个工具的设计取舍，也是使用时的判断标准。

  1. 本地优先 剧本与音频只写入本地存档，数据不出这台电脑；唯一外部依赖是 edge 在线合成和可选的 DeepSeek 精修。
  2. 一个角色，一个音色 种子音色与 roleBase 身份键保证同一角色跨集复用同一声音，界面会标注“已复用”。
  3. 流程一条直线 上传 → 场标 → 角色 → 声音 → 合成 → 围读 → 续读，默认值已能跑通，设置只是精调。
  4. 规则打底，人工接手 解析、性别年龄、自动分配都有规则兜底；确认页随时可改，AI 只是减少重复劳动。

03 · 使用技巧

少踩坑，一次成型

按上传前、合成前、续读前三个阶段排列的高频技巧。

  1. 文件名带集号

    写“第1集”“第一集”等，多集上传后自动排序并独立计场，否则多集文件容易被当成同集处理。

  2. 先跑一集再批量

    用一集测试剧本走完流程，确认场标与角色识别无误，再上传后续集数，返工成本最低。

  3. 先试听种子音色

    Qwen 模式下先为每个角色生成种子音色并试听，满意后再批量合成；种子决定全剧声音统一。

  4. 先启用音色位

    自动分配只在“已启用”的音色池里找；角色多时先启用更多档位，避免“可用音色不足”。

  5. 同剧不换音源

    音源锁在剧级，切回续读时不要在同剧内混用 edge 与 Qwen，否则角色声音可能不一致。

  6. 存档目录别乱换

    默认 ~/Documents/剧本围读存档，第一次保存时自动创建；改目录等于换一套存档，共享要拷贝整个文件夹。

04 · 常见问题

问答

安装、运行与存档的快速对照。

需要什么电脑？
Apple Silicon Mac（M1 及以上）。16GB 内存可跑 Qwen3 1.7B；更小的机器建议全程用 edge-tts。
Qwen 报错或生成超时？
服务必须用 .venv-qwen/bin/python 启动；生成有 180 秒超时并会自动重建 worker，卡住后重试即可，日志在 logs/sr_qwen.log。
前端打不开怎么办？
确认 5174、9882、9883、9884 四个端口健康、dist/ 存在；日志都在 logs/ 目录。
存档找不到？
默认目录是 ~/Documents/剧本围读存档，第一次保存时懒创建；换目录等于换一套存档。
edge 合成失败？
edge-tts 使用微软在线音色，需要联网；检查网络后重试即可。
