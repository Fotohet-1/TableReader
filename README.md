# 剧本围读

上传剧本，自动拆出角色、预判性别和年龄段，按角色分配音色后分角色朗读。支持流式合成：满 25 句（或整剧不足 25 句时全部完成）即可提前进入围读，后台继续合成。

## 功能

- 上传 .docx / .txt / .md，或直接粘贴文本
- 行级解析：场标、对白、动作、旁白
- 角色写法归并（熊黑严肃 → 熊黑），规则预判性别，可选 DeepSeek 精修
- 两种 TTS：edge-tts 快速模式、本地 CosyVoice（支持上传音频克隆专属音色）
- 音色库：14 个中文基础音色 × 5 档语调 = 70 个独立音色位，每个档位可单独打性别、年龄、方言标签，支持试听、批量、导出/导入
- 围读播放：当前句高亮、自动滚动、0.5x-3x 倍速、±5s/±10s 跳转、进度条拖动

## 启动

```bash

npm run dev
```

## 音色库

工作台顶部打开“音色库”，14 个中文基础音色各一张卡：

- 每张卡内 5 行，分别对应低沉/微沉/原声/微亮/清亮，每行可试听、可单独设置性别/年龄/方言
- 每行有“特殊”标记：方言音色和少年档默认标为特殊，普通话常规音色为通用，可手动改
- 音色名在卡头统一修改，“复制原声到整组”可把原声档的标签铺到其他 4 档
- 勾选多张卡后，可用“批量”一次设置性别/年龄/方言
- “导出 JSON”下载当前标签，“导入 JSON”合并回浏览器

标签存在浏览器 localStorage。分配角色音色时，下拉会显示“晓晓·低沉 · 女 · 老年”这类带标签的名称，并可先按性别/年龄/方言筛选。

角色多时自动分配按分层走：先按角色性别年龄匹配标签（通用音色优先，特殊音色只在真有对应角色时用），再用通用音色池，最后才动特殊音色。合适的未占用音色用完后允许重复，但优先挑最合适的重复。

每个音色后面会显示当前持有它的角色数，默认 1；手动选择某个已被占用的音色时，数字变成 2，两个角色共享同一个声音，原占用者不会被踢走。想释放音色就把角色改成“未分配”。
